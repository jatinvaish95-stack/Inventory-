# CITY GROUP — Stock Manager

Version 1 is a free, browser-based prototype.

- Voice command + typed command
- Product inventory
- Stock In / Stock Out
- Inventory value
- Search
- No Google Sheets
- No Apps Script
- No transaction-history module
- Data is stored locally in the browser for this first test

Next phase: move the inventory data to a free shared backend so the same stock can be used on 5 devices.
